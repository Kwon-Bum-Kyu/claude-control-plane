# Token Scenario Design — 토큰 측정 시나리오 설계 절차

CCP의 MVP 합격선(15%+ 절감, 라우터 80%+ 정확도)을 검증하기 위한 측정 시나리오 설계 가이드.

## 시나리오 5축

모든 측정 시나리오는 다음 5축을 명시한다:

| 축 | 설명 | 예시 |
|----|------|------|
| **입력 워크로드** | 측정에 사용할 작업 | "1만 라인 코드베이스 요약" |
| **비교 대상** | A/B 비교 (필수) | A=Claude 단독, B=Claude+라우터 |
| **측정 항목** | 무엇을 측정 | input tokens, output tokens, wall time |
| **합격 기준** | 통과 조건 | "B가 A 대비 15%+ 절감" |
| **회귀 신호** | 실패로 판정할 신호 | "B가 A보다 토큰 더 사용" |

## 시나리오 작성 템플릿

```markdown
### T{N}. {시나리오 이름}

- **입력:** {구체적 워크로드, 재현 가능하게}
- **비교:**
  - A (baseline): Claude 단독 처리
  - B (with CCP): Claude + 라우터 → Gemini 위임
- **측정:**
  - input_tokens (메인 + 서브에이전트 합계)
  - output_tokens (메인 + 서브에이전트 합계)
  - wall_time (초)
- **합격:** B의 input_tokens ≤ A의 input_tokens × 0.85
- **회귀:** B의 input_tokens > A의 input_tokens (즉시 차단)
- **연관 리스크:** R1 / R2 / R3 (해당하는 것 명시)
```

## 권장 시나리오 5개 (T1~T5)

| ID | 시나리오 | 예상 절감 효과 | 검증 리스크 |
|----|---------|--------------|-----------|
| T1 | 1만 라인 코드베이스 요약 | Gemini 1M 컨텍스트, 입력 58%↓ | R2 |
| T2 | 단일 파일 리팩터 (라우터 우회) | 라우터가 위임 안 함 (Claude 본체) | R3 (오판 시 위임) |
| T3 | 대용량 로그 파싱 (background job) | Gemini 위임, 결과 파일 경로만 반환 | R1 |
| T4 | 짧은 Q&A 반복 10회 | Claude 본체, 라우터 비용만 누적 | R3 (라우팅 토큰) |
| T5 | 컨텍스트 75% 도달 시점 | suggest-compact 발화 | R5 |

## 라우터 정확도 평가 데이터셋 설계

### 데이터셋 요구사항

- **최소 N=30** 케이스 (정답 라벨 있음)
- **균등 분포**: Claude 위임 / Gemini 위임 케이스 비율 50:50
- **경계 케이스 포함**: 명확한 케이스만 모으면 정확도가 과대평가됨
  - 명확: "1만 라인 요약" (Gemini), "한 줄 fix" (Claude)
  - 경계: "100라인 파일 분석" — 어느 쪽도 정답 가능

### 정확도 측정 방법

```
정확도 = 정답_일치 / 전체
```

**합격:** 80%+
**경계 케이스만 빼서 재측정:** 60%+ (보수적)

## 회귀 케이스 설계

회귀 케이스는 "절감 시나리오 5개"보다 가치 있다. 다음 R-매핑:

| 회귀 케이스 | 매핑 리스크 | 측정 방법 |
|-----------|-----------|----------|
| 서브에이전트 출력이 메인에 그대로 흘러듦 | R1 | 호출 전후 메인 컨텍스트 토큰 ΔT |
| Gemini 응답 길이 가드 미동작 | R2 | `max_output_tokens` 미명시 호출로 응답 크기 확인 |
| 라우터가 잘못 위임 → 2중 호출 | R3 | 의도적 오라우팅 케이스 주입 |
| OAuth 만료 시 재인증 안내 누락 | R6 | 토큰 만료 시뮬레이션 |

## Why

ecc·omc가 표방한 "30~50% 절감"이 검증 불가로 판정된 이유(보고서 §5)는 측정 시나리오 부재였다. CCP는 동일한 함정을 피하려면 **모든 합격 기준을 사전 정의된 시나리오로 검증**해야 한다. 5축 구조는 측정 가능성을 강제한다.
